# Cas support — sous-catégories par thème
_Analyse sur 180 jours · 1 667 tickets · département Support_

---

## 1. Accès & Authentification
_Cross-produit — ~200 tickets (CRM, Dmbook Pro, Hub, Kiosque, Guest App)_

- Connexion impossible / session expirée
- Mot de passe oublié / code unique
- Création de compte utilisateur (nouveau collaborateur)
- Désactivation / réactivation d'utilisateur
- Accès multi-propriété (droits insuffisants sur plusieurs établissements)
- 2FA — problème de configuration ou de réception

---

## 2. Intégration & Connectivité PMS
_114 tickets_

- Nouvelle demande de connectivité (onboarding PMS)
- Migration PMS (changement de système — ex. HotSoft → Mews)
- Flux 2-way cassé ou données non remontées (réservations manquantes, merge)
- Merge intempestif (fusion involontaire de profils)
- Import CSV non pris en compte
- Absence de messages depuis le PMS (silent failure)

---

## 3. Campagnes & Délivrabilité
_~200 tickets (Campagne Email + Newsletters + WhatsApp + Email delivery)_

- Campagne non envoyée (bloquée, annulée sans raison)
- Délivrabilité (DNS mal configuré, quota dépassé, format email invalide)
- Envoi inattendu ou envoi au mauvais destinataire
- Ciblage / segmentation incorrecte
- Paramétrage (expéditeur, footer, traduction, BCC)
- Duplication / copie de campagne
- Programmation / envoi test
- WhatsApp — non délivré / compte désactivé

---

## 4. Données Clients & CRM
_75 tickets (Guest profile)_

- Mélange de données entre deux profils
- Profil à anonymiser (RGPD)
- Email client incorrect / manquant
- Confirmation de réservation non reçue par le client
- Envoi automatique pré/post-séjour ne se déclenche pas
- Export liste clients (VIP, séjour, données brutes)
- API réseaux sociaux / questions intégration tiers

---

## 5. Interface, Contenu & Formulaires
_~85 tickets (Guest App + Pages + Formulaires)_

- Bug d'affichage (page, app, formulaire)
- Modifications visuelles demandées par le client (photos, couleurs, logo)
- Formulaire non fonctionnel (bouton, champ, logique)
- Notification de réponse formulaire absente dans le Hub
- Ajout / suppression de page ou d'onglet
- Lenteur extrême sur tablette

---

## 6. Hub de Messagerie
_49 tickets_

- Accès / connexion au Hub
- Message non envoyé ou non reçu
- Message automatique ne s'affiche pas
- Message personnel reçu à tort dans le Hub professionnel
- Envoi de groupe / multi-canal (SMS, WhatsApp, email depuis Hub)
- Suppression d'un envoi programmé

---

## 7. Services à Bord
_~57 tickets (Check-in + Module de commande)_

**Check-in online**
- Lien check-in non fonctionnel
- Fiche de police
- Pré-autorisation disparue
- Problème sur tablette / iPad
- Mails de pré check-in non envoyés

**Module de commande (room service, F&B)**
- Notification de nouvelle commande non reçue
- Bug sur la configuration (onglets, menus)
- Intégration Hub vs. automatisation (conflit de notifications)

---

## 8. Statistiques & Exports
_21 tickets_

- Export de données non reçu ou retardé
- KPIs campagnes incohérents
- Statistiques affichent une mauvaise date / période
- Rapport quotidien absent
- Page statistiques en erreur

---

## 9. Sécurité & Conformité
_~15 tickets (Phishing + RGPD + 2FA)_

- Compromission de compte (WhatsApp, CRM)
- Phishing ciblant un hôtel via LoungeUp
- Demande d'anonymisation RGPD
- DNS — configuration SPF/DKIM

---

## 10. Dmbook Pro
_42 tickets_

- Accès utilisateur (création, multi-propriété)
- Bug fonctionnel (checklist, tâche impossible à cocher)
- Intégration PMS (données non poussées vers Medialog, etc.)

---

## 11. Kiosque Presse
_28 tickets_

- Accès / activation (nouveau client, nouveau terminal)
- Code hebdomadaire non reçu
- Mise à jour des titres / suppression
- Modification destinataire des codes

---

## Note — catégorie "Other" (633 tickets)

Fourre-tout à distinguer en trois types :

1. **Notifs automatiques parasites** — "événements en attente" ×50, "appel répondu" ×28 → à filtrer, pas des cas support réels
2. **Tickets mal catégorisés** — connexion, export, questions générales → à redistribuer dans les thèmes ci-dessus
3. **Demandes de suppression d'établissement** ×5 → procédure spécifique off-boarding
